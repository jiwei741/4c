## 强图结构结果

旧图结构：

- 模型：`ST-GNN + wind_radius + EDGAR + feature norm`
- 指标见 [metrics.json](../services/inference/outputs/stgnn_gcn_lstm_nanjing_quarterly_qc_edgar_wind_norm/metrics.json)
- `MAE = 0.057154`
- `RMSE = 0.075623`

新图结构：

- 模型：`ST-GNN + hybrid_wind_knn + EDGAR + feature norm`
- 指标见 [metrics.json](../services/inference/outputs/stgnn_gcn_lstm_nanjing_quarterly_qc_edgar_hybrid_norm/metrics.json)
- `MAE = 0.055481`
- `RMSE = 0.073544`

结论：

- 新图结构相比原 `wind_radius` 有提升
- `MAE` 降低约 `2.9%`
- `RMSE` 降低约 `2.7%`

### LSTM 2-step

- 输出目录：[lstm_baseline_nanjing_quarterly_qc_edgar_multistep](../services/inference/outputs/lstm_baseline_nanjing_quarterly_qc_edgar_multistep)

- 如果以整体误差稳定性和极端误差控制为主，当前 `2-step ST-GNN` 更适合当多步主模型

## 情景推演增强结果

基础场景：

- 样例：[nanjing_qc_edgar_scenario.json](../services/inference/examples/nanjing_qc_edgar_scenario.json)
- 输出：[simple_scenario.json](../services/inference/outputs/stgnn_gcn_lstm_nanjing_quarterly_qc_edgar_hybrid_norm/simple_scenario.json)

增强场景：

- 样例：[nanjing_industrial_expansion_enhanced.json](../services/inference/examples/nanjing_industrial_expansion_enhanced.json)
- 输出：[enhanced_scenario.json](../services/inference/outputs/stgnn_gcn_lstm_nanjing_quarterly_qc_edgar_hybrid_norm/enhanced_scenario.json)

两者对比：

- 基础场景：
  - `max_abs_delta = 0.001284`
  - `mean_abs_delta = 0.0000135`
  - `|delta| > 1e-4` 的节点数：`8`
  - `|delta| > 1e-3` 的节点数：`1`
- 增强场景：
  - `max_abs_delta = 0.003331`
  - `mean_abs_delta = 0.0000959`
  - `|delta| > 1e-4` 的节点数：`48`
  - `|delta| > 1e-3` 的节点数：`8`

结论：

- 增强场景的最大响应约为基础场景的 `2.6x`
- 平均响应约为基础场景的 `7.1x`
- 有明显更多节点被卷入扰动范围

## 最终判断

本轮三项工作都值得保留：

1. 多步预测：已可用，且 `2-step ST-GNN` 的 `RMSE` 优于 `2-step LSTM`
2. 更强图结构：已带来单步指标提升，建议替换原 `wind_radius`
3. 情景推演增强：响应明显变强，比原来更适合演示“工业扩张影响扩散”

## 当前建议

如果现在要确定默认方案，建议这样定：

- 单步主模型：
  - `ST-GNN + hybrid_wind_knn + EDGAR + feature norm`
- 多步主模型：
  - `2-step ST-GNN + hybrid_wind_knn`
- 演示场景：
  - 使用增强版 `industrial_expansion` 场景，而不是简单常量加减场景
