### 3. 开源许可证还没定

真正推 public 前，建议补一个许可证文件。  
常见选择：

- `MIT`
- `Apache-2.0`
- `GPL-3.0`

这个需要你们团队自己定。

## 推荐发布顺序

1. 初始化 git

```powershell
cd d:\4c
git init -b main
```

2. 检查忽略效果

```powershell
git status --ignored
```

3. 只添加你要公开的内容

```powershell
git add .
git status
```

重点确认以下内容**没有**出现在 staged 列表中：

- `.env`
- `data/raw`
- `data/processed`
- `logs`
- `remote_sensing_output`
- `remote_sensing_output_ver.03.20`
- `external`

4. 写首个提交

```powershell
git commit -m "chore: prepare public repository"
```

5. 创建远程 public 仓库后推送

```powershell
git remote add origin <your-public-repo-url>
git push -u origin main
```
