## 推荐发布顺序

1. 初始化 git

```powershell

git init -b main
```

2. 检查忽略效果
```powershell
git status --ignored
```

3. 确认以下内容没有进入暂存区
- `.env`
- `data/raw/`
- `data_for_memberA/`

```powershell

```
