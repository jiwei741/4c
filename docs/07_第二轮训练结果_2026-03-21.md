# 第二轮训练结果（2026-03-21）

## 本轮修正

1. `MOD17A2HGF.061 / Gpp_500m` 标签抽取补上了 `scale factor = 0.0001`。
2. 引入 `Psn_QC_500m` 质量过滤：
   - 仅接受 `MODLAND good`
   - `dead detector = 0`
   - `SCF_QC in {0, 1}`
3. `AppEEARS` 边缘缺口导致固定少量节点无标签，采用三层补齐：
   - 优先使用 `QC` 标签
   - 缺少 `QC` 时回退到同节点、同季度的 `scaled GPP`
   - 仍缺失时，用同季度最近邻节点标签填补

## 标签数据

- 原始严格 `QC` 标签：`5874` 行
- 同节点回退补齐：`6` 行
- 最近邻补齐：`609` 行
- 最终完整季度标签：`6489` 行（`21` 个季度，`309` 节点）

最终训练交集使用 `2020-Q1` 到 `2024-Q4` 共 `20` 个季度。

## 第二轮实验

统一数据集：
- `data/processed/inference/nanjing_quarterly_qc_v1.npz`
- 形状：`x=[20,309,8]`，`y=[20,309,1]`

统一模型结构：
- `ST-GNN (GraphConv + LSTM)`
- `input_window=4`
- `horizon=1`

对比设置：
1. `QC + identity`
2. `QC + log1p`
3. `QC + quantile clip (0.95)`

所有指标都已反变换回原始标签尺度比较。

## 指标

### ST-GNN

| 配置 | MAE | RMSE |
|---|---:|---:|
| QC + identity | 0.12657 | 0.14743 |
| QC + log1p | 0.12634 | 0.14895 |
| QC + clip95 | 0.12647 | 0.14783 |

### LSTM baseline

| 配置 | MAE | RMSE |
|---|---:|---:|
| QC + identity | 0.12687 | 0.14708 |

## 结论

1. 这轮真正带来大幅改善的不是 `log1p` 或裁剪，而是：
   - 修正 `GPP scale factor`
   - 引入 `Psn_QC_500m`
   - 重新构建完整标签
2. `log1p` 在 `MAE` 上略优，但优势非常小；同时 `RMSE` 变差。
3. `clip95` 没有带来明显收益。
4. 如果只看 `ST-GNN` 三组，推荐保留 `QC + identity` 作为当前默认方案：
   - 配置最简单
   - `RMSE` 更稳
   - 和 `log1p` 的 `MAE` 差距很小
5. 当前 `ST-GNN` 还没有明显拉开与 `LSTM baseline` 的差距，说明后续提升重点应放在：
   - 更高质量标签
   - 更细致的图结构
   - 更长时间序列
