# 平台联调与启动说明

更新时间：`2026-03-29`

## 当前可本地运行的部分

- `services/backend`
  - 聚合模型结果
  - 提供预测、分析、情景推演和平台状态接口
- `services/frontend`
  - Vue 3 + Vite 前端页面
  - Cesium 地图与情景推演交互
- `services/inference`
  - 已训练模型
  - 预测脚本与情景推演脚本
- `services/data_ingestion`
  - 数据接入骨架
- `services/streaming`
  - 流式与数据库骨架

## 当前不在本机运行的部分

- 大规模原始遥感批处理
- 任何旧的远程分割服务链路

## 运行前提

1. 已安装 `uv`
2. 已安装 Node.js `^20.19.0 || >=22.12.0`
3. 根目录 `.env` 已存在
4. 端口未被占用
   - `8000`：backend
   - `4173`：frontend

## 一键启动

```powershell
cd d:\4c
powershell -ExecutionPolicy Bypass -File scripts/start_platform.ps1
```

跳过自动打开浏览器：

```powershell
cd d:\4c
powershell -ExecutionPolicy Bypass -File scripts/start_platform.ps1 -NoBrowser
```

强制重新同步依赖：

```powershell
cd d:\4c
powershell -ExecutionPolicy Bypass -File scripts/start_platform.ps1 -ForceSync
```

## 停止平台

```powershell
cd d:\4c
powershell -ExecutionPolicy Bypass -File scripts/stop_platform.ps1
```

## 联调测试

```powershell
cd d:\4c

```

## 常见问题

### 1. 端口被占用

先停止已有进程，再重新执行启动脚本。

### 2. `uv sync` 或 `npm ci` 失败

确认网络、写权限和本地环境安装后，再执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start_platform.ps1 -ForceSync
```

### 3. 前端可以打开但没有数据

先确认后端健康检查通过，再确认根目录 `.env` 中的端口配置与当前启动端口一致。
