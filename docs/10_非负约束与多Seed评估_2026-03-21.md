# 非负约束与多 Seed 评估

日期：2026-03-21

## 本轮修改

本轮针对成员 A 的模型训练与推理链路，完成了两类改动：

1. 给推理输出增加可配置的预测约束：
   - 在训练评估阶段支持 `prediction_constraints`
   - 在单次推理 `predict.py` 中生效
   - 在情景推演 `run_scenario.py` 中生效
2. 增加多 seed 对比脚本：
   - `services/inference/run_multi_seed_experiment.py`
   - 用于比较同一模型在不同随机种子下的波动情况

## 关键修复

在做非负约束前，先发现了一个更基础的问题：

- 旧版 `train.py` 在开启目标归一化后，会覆盖掉特征归一化信息
- 结果是旧 checkpoint 只保存了 `target` normalization，没有保存 `features` normalization
- 这会导致推理阶段输入没有按训练时相同方式标准化，出现明显错误

这个问题会直接污染推理结果。旧 checkpoint 的典型现象是：

- [旧 ST-GNN 推理结果](../services/inference/outputs/stgnn_gcn_lstm_nanjing_quarterly_qc_edgar_wind_norm/latest_prediction_legacy_checkpoint.json)
- 输出整体为负值，明显不合理

修复后，新 checkpoint 会同时保存：

- `normalization.features`
- `normalization.target`
- `prediction_constraints`

对应示例：

- [新 ST-GNN 非负约束 metrics](../services/inference/outputs/stgnn_gcn_lstm_nanjing_quarterly_qc_edgar_wind_norm_nonneg/metrics.json)

以 `seed=42` 为例：

- ST-GNN 无约束：`MAE 0.057154`，`RMSE 0.075623`
- ST-GNN 非负约束：`MAE 0.057154`，`RMSE 0.075623`

说明：

- 对当前最优配置，加入非负约束后，单次 seed 的分数基本不变
- 修复 checkpoint 后，无约束模型本身已经能给出非负预测

## 额外核验

情景推演链路也已验证非负约束不会导致报错：

- [ST-GNN 情景推演结果](../services/inference/outputs/stgnn_gcn_lstm_nanjing_quarterly_qc_edgar_wind_norm_nonneg/seed_42/latest_scenario.json)

当前情景扰动响应仍然偏弱，说明问题不在“输出为负”，而在于：

- 训练样本仍然短
- 图结构仍然偏简化
- 情景扰动信号还不够强

## 最终评估

本轮“非负约束 + 多 seed 对比”的结论是：

1. 非负约束这项修改可以保留，因为它是安全的，而且能防止旧 checkpoint 或异常输入导致物理上不合理的负值输出。
2. 但对当前最优模型，它不是主要提分项。
3. 之前看到的大量负值，核心原因是旧 checkpoint 没保存 `features` normalization，而不是模型头必须做裁剪。
4. 目前真正影响分数的，仍然是：
   - 特征标准化
   - EDGAR 特征接入
   - 风向加权图
5. 当前综合表现仍然是：
   - 最稳的图模型：`ST-GNN + EDGAR + feature norm + wind graph`
   - 最好的纯分数：`LSTM + EDGAR + feature norm`

## 建议

下一步优化优先级建议如下：

1. 继续保留非负约束支持，但不要把它当成主优化方向。
2. 后续汇报时，明确把“旧 checkpoint 归一化信息缺失”说明为已修复工程问题。
3. 真正值得继续做的，是：
   - 更强的图结构
   - 更高时间分辨率数据
   - 更真实的排放扰动设计
   - 多步预测而不是只做 1-step
