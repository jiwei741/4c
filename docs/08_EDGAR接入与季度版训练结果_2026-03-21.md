# EDGAR 接入与季度版训练结果（2026-03-21）

## 本轮新增

1. 从官方 `EDGAR_2025_GHG` 下载工业相关 `CO2` sector 年度网格图：
   - `ENE`
   - `IND`
   - `PRO_FFF`
   - `CHE`
2. 将年度网格按南京 `309` 节点做最近邻映射。
3. 将年度值按年复制到四个季度，生成季度训练特征。

输出文件：
- `data/raw/edgar/nanjing/*.zip`
- `data/processed/features/nanjing/quarterly/edgar_features.csv`
- `data/processed/inference/nanjing_quarterly_qc_edgar_v1.npz`

## EDGAR 特征口径

- 物质：`CO2`
- 版本：`EDGAR_2025_GHG`
- 时间：`2020-2024`
- 单位：`megatonnes`
- 当前训练列：`edgar_emission`
- 当前构造方式：`ENE + IND + PRO_FFF + CHE` 求和

## 分布

- `edgar_emission` 最小值：`0.0`
- 最大值：`24.8232`
- 平均值：`0.8639`

说明：
- `PRO_FFF` 在南京节点上几乎可以忽略。
- 当前 EDGAR 是“年度复制到季度”，因此它提供的是低频排放背景，而不是季度内动态变化。

## 训练对比

### ST-GNN

| 配置 | MAE | RMSE |
|---|---:|---:|
| QC + 无 EDGAR | 0.12657 | 0.14743 |
| QC + EDGAR | 0.12777 | 0.14550 |

### LSTM baseline

| 配置 | MAE | RMSE |
|---|---:|---:|
| QC + 无 EDGAR | 0.12687 | 0.14708 |
| QC + EDGAR | 0.12640 | 0.14879 |

## 结论

1. `EDGAR` 接入后，`ST-GNN` 的 `RMSE` 有改善，但 `MAE` 变差。
2. `EDGAR` 接入后，`LSTM` 的 `MAE` 有改善，但 `RMSE` 变差。
3. 这说明 `EDGAR` 确实带来了新的信息，但当前收益还不稳定。
4. 从预测分布看，`ST-GNN` 加入 EDGAR 后节点预测标准差明显增大，说明空间差异表达有所增强；但整体仍然偏向均值预测。
5. 下一步最值得尝试的不是继续堆更多 sector，而是：
   - 图结构改成距离 + 风向权重
   - 对输入特征做统一标准化
   - 如果可能，换成更高时间分辨率的排放代理
