# 南京季度版小模型数据现状

本文档用于说明成员 AA 当前可直接使用的数据、已经打通的脚本链路，以及训练前仍需补齐的数据。

## 已经准备好的数据

- 季度遥感输入
  - [grid_nodes.csv](../data/processed/features/nanjing/quarterly/grid_nodes.csv)
  - [sentinel2_features.csv](../data/processed/features/nanjing/quarterly/sentinel2_features.csv)
  - 当前规模：`309` 个节点，`2020-Q1` 到 `2024-Q4` 共 `20` 个季度时间步

- ERA5 月度原始下载
  - era5_land_monthly_nanjing_2020_2024.nc (`data/raw/era5/nanjing/era5_land_monthly_nanjing_2020_2024.nc`)
  - 注意：这个文件外层是 `zip` 容器，内部是真正的 `data_stream-moda.nc`

- ERA5 月度点位表
  - [era5_monthly_points.csv](../data/processed/features/nanjing/monthly/era5_monthly_points.csv)
  - 当前规模：`309` 节点 x `60` 个月 = `18540` 行

- ERA5 季度特征表
  - [era5_features.csv](../data/processed/features/nanjing/quarterly/era5_features.csv)
  - 当前规模：`309` 节点 x `20` 季度 = `6180` 行

## 还缺的数据

- GPP 月度 GeoTIFF
  - 目录：data/raw/gpp/nanjing/monthly (`data/raw/gpp/nanjing/monthly`)
  - 当前缺口：`2020-01` 到 `2024-12` 共 `60` 个月全部缺失
  - 文件命名必须严格使用：`map_YYYYMM.tif`

- 季度标签表
  - 目标路径：[labels.csv](../data/processed/features/nanjing/quarterly/labels.csv)
  - 只有在月度 GPP GeoTIFF 准备好后，才能由脚本自动生成

  - [extract_nanjing_gpp_quarterly_labels.py](../services/inference/extract_nanjing_gpp_quarterly_labels.py)

  - [check_nanjing_quarterly_training_readiness.py](../services/inference/check_nanjing_quarterly_training_readiness.py)

## 当前训练结论

- 现在已经具备：
  - `grid_nodes.csv`
  - `sentinel2_features.csv`
  - `era5_features.csv`

- 现在还不具备：
  - `labels.csv`

因此，当前还不能正式训练季度版监督模型。  
唯一剩余硬缺口是：补齐 `GPP` 月度 GeoTIFF，然后生成 [labels.csv](../data/processed/features/nanjing/quarterly/labels.csv)。

## 队友需要提供什么

队友只需要把月度 GPP `GeoTIFF` 放到：

```text
data/raw/gpp/nanjing/monthly/
```

并严格命名为：

```text
map_202001.tif
map_202002.tif
...
map_202412.tif
```

详细规范见：
- [04_GPP月度GeoTIFF命名与目录规范.md](04_GPP月度GeoTIFF命名与目录规范.md)

## 拿到 GPP 后的执行顺序

```bash
cd services/inference
uv run --offline python validate_gpp_monthly_directory.py --input-dir ../../data/raw/gpp/nanjing/monthly
uv run --offline python extract_nanjing_gpp_quarterly_labels.py --tif-dir ../../data/raw/gpp/nanjing/monthly
uv run --offline python build_training_dataset.py --config configs/nanjing_quarterly_dataset.yaml
uv run --offline python train.py --config configs/lstm_baseline_quarterly.yaml --dataset ../../data/processed/inference/nanjing_quarterly_v1.npz
uv run --offline python train.py --config configs/stgnn_gcn_lstm_quarterly.yaml --dataset ../../data/processed/inference/nanjing_quarterly_v1.npz
```
