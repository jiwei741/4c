# 特征标准化与风向图优化结果（2026-03-21）

## 优化内容

本轮针对季度版南京训练集做了两项结构性优化：

1. **输入特征标准化**
   - 按训练集统计 `mean/std`
   - 训练时对输入特征做标准化
   - 推理与情景推演阶段复用同一组统计量

2. **风向加权邻接矩阵**
   - 仍以空间邻近为基础
   - 在半径图上叠加 `u10_wind / v10_wind` 方向一致性权重
   - 用于替代纯 `radius` 的静态 0/1 邻接

## 数据集

### EDGAR 版基础数据集
- `data/processed/inference/nanjing_quarterly_qc_edgar_v1.npz`
- 特征数：`9`
- 邻接：纯半径图，平均出度约 `14.4`

### EDGAR + 风向图数据集
- `data/processed/inference/nanjing_quarterly_qc_edgar_wind_v1.npz`
- 特征数：`9`
- 邻接：风向加权图，平均出度约 `14.4`

## 对比结果

### ST-GNN

| 配置 | MAE | RMSE |
|---|---:|---:|
| QC + 无 EDGAR | 0.12657 | 0.14743 |
| QC + EDGAR | 0.12777 | 0.14550 |
| QC + EDGAR + feature norm | 0.05985 | 0.07886 |
| QC + EDGAR + feature norm + wind graph | 0.05715 | 0.07562 |
| QC + EDGAR + feature norm + kNN6 | 0.05894 | 0.07771 |

### LSTM baseline

| 配置 | MAE | RMSE |
|---|---:|---:|
| QC + EDGAR | 0.12640 | 0.14879 |
| QC + EDGAR + feature norm | 0.05303 | 0.07072 |

## 结论

1. 当前最大收益来自 **输入特征标准化**，不是继续改 `log1p/clip`。
2. `ST-GNN` 在加入标准化后显著提升，说明之前主要被特征尺度问题拖住。
3. 风向加权图比纯半径图更好，也优于 `kNN6`。
4. 但截至当前，**最优模型仍然是 LSTM baseline + feature norm**：
   - `MAE = 0.05303`
   - `RMSE = 0.07072`
5. 当前最优 `ST-GNN` 是：
   - `QC + EDGAR + feature norm + wind graph`
   - `MAE = 0.05715`
   - `RMSE = 0.07562`

## 对成员 A 的建议

如果目标是“当前阶段先拿到最好分数”，优先展示：
- `LSTM baseline + feature norm` 作为最佳精度模型

如果目标是“答辩强调方法先进性”，优先展示：
- `ST-GNN + EDGAR + feature norm + wind graph`

更合理的说法是：
- `LSTM` 负责最好分数
- `ST-GNN` 负责体现项目的时空图建模创新性

## 剩余问题

1. 最优 `ST-GNN` 仍未超过最优 `LSTM baseline`
2. 最新一步推理时，仍可能出现不符合物理意义的负值预测，后续建议加入：
   - 非负约束输出
   - 或更合适的目标定义/变换
3. 当前 EDGAR 还是年度复制到季度，不是真正季度动态排放
